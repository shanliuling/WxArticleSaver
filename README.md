# WxArticleSaver

> 本地运行的微信公众号文章归档工具。打开你**可以正常阅读**的公众号文章，点击右下角 **「导出本文」**，即可保存文章正文、图片及可直接获取的媒体资源。

**当前平台：Windows 10 / Windows 11**  
**License：GNU AGPL-3.0**

## 功能

- 在微信文章页注入「导出本文」按钮
- 导出 Markdown / HTML / TXT
- 图片本地化保存
- 保存文章元数据与原始页面快照
- 支持直接媒体文件与未加密 HLS 视频的尽力下载
- 微信 WebView 命中缓存时，尝试自动刷新一次
- 仅在点击「导出本文」后写入文章文件

## 快速开始

### 1. 环境要求

- Windows 10 / 11
- Python 3.11 或 3.12

### 2. 启动

下载源码后双击：

```text
install_and_run.bat
```

首次运行会安装 Python 依赖，并在**当前 Windows 用户**下临时信任本机生成的代理证书。

### 3. 导出文章

1. 启动 WxArticleSaver 后，完全退出微信并重新打开。
2. 打开你可以正常阅读的公众号文章。
3. 点击文章右下角 **「导出本文」**。
4. 如果没有看到按钮，请按 **Ctrl+R**，或在文章页面内 **右键 → 刷新** 后重试。
5. 如果文章包含视频，建议先播放几秒，再点击「导出本文」。

导出内容默认保存在：

```text
exports/
└─ 文章标题/
   ├─ article.md
   ├─ article.html
   ├─ article.txt
   ├─ raw_wechat_response.html
   ├─ meta.json
   ├─ images/
   └─ videos/
```

## 为什么有时需要刷新？

Windows 微信可能直接从 WebView 页面缓存恢复已经打开过的文章，此时不会重新请求文章主 HTML，WxArticleSaver 就没有机会注入导出按钮。

程序会在能够确认前台窗口是微信时，**尽力自动发送一次 Ctrl+R**。如果自动刷新没有触发，手动按 Ctrl+R 或右键刷新即可。

## 视频说明

微信文章中的视频通常不会直接把真实媒体地址写在初始 HTML 里，因此建议先播放几秒，让页面实际请求媒体资源，再执行导出。

当前策略：

- 直接 MP4 / WebM / MOV 等：尽力下载
- 未加密 HLS / m3u8：尽力下载并合并
- 加密 HLS：不解密，仅保留可用链接
- DRM：**不绕过**

## 安全设计

WxArticleSaver 使用本地 `mitmproxy` 读取并修改微信文章 HTTPS 响应，因此首次运行需要在当前用户证书库中临时信任一个**由本机生成**的 CA。

网络范围通过 PAC 限制为：

```text
微信文章 / 少量腾讯视频域名
        ↓
127.0.0.1 本地 mitmproxy

其他网站
        ↓
DIRECT（不进入 WxArticleSaver）
```

当前代理范围包括 `mp.weixin.qq.com` 以及导出视频所需的少量腾讯媒体域名。其他网站保持直连。

程序正常退出时会：

- 恢复启动前的 Windows 系统代理设置
- 停止本地 PAC / mitmproxy
- 从当前用户「受信任的根证书」中移除 WxArticleSaver 使用的 CA

CA 文件仍保存在本机 `.wxas_ca/`，用于下次运行，**不会上传**。如果不再使用本工具，可运行 `remove_certificate.bat` 清理证书；代理异常时可运行 `restore_proxy.bat` 恢复代理。

### 数据处理

文章内容默认只保存在本机。工具不会持久化或复用以下敏感凭据用于媒体下载：

- Cookie
- Authorization
- `pass_ticket`

运行时目录、证书文件、代理备份、日志和导出内容均已加入 `.gitignore`。

## 常见问题

### 没有出现「导出本文」怎么办？

先在当前文章页按 **Ctrl+R**，或 **右键 → 刷新**。这是目前最常见的情况，通常由微信 WebView 页面缓存导致。

### 退出后网络不正常怎么办？

运行：

```text
restore_proxy.bat
```

### 想移除工具安装过的根证书怎么办？

运行：

```text
remove_certificate.bat
```
